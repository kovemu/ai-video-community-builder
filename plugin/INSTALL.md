# Install v3 once

1. Download the v3 installer package.
2. In Figma Desktop: Plugins → Development → Import plugin from manifest…
3. Choose `manifest.json`.
4. Run **AI Video Community Builder**.
5. Click **GitHub 최신 버전 불러오기** or **최신 버전으로 전체 화면 다시 생성**.

After this one-time bootstrap install, normal screen/data changes are pulled from GitHub without replacing local plugin files.
